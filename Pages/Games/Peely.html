Introduction


Peely was made for Xamk's Fuxi Game Jam 2024. The theme was the old Metsola campus. In our game you play as a student stuck in the old campus after closing hours. To escape you must collect 8 kumi-potatoes, but this objective is not so simple. The old campus's halls are haunted by a reanimated peeler called Peely. Collect the potatoes while avoiding Peely to escape the old campus's grasp.

Project Details

My Contributions

  1. Learning about game development and new systems

    This project was my very first time programming inside a game engine (Unity) and using C#. During the 48-hour game jam, I focused on learning how scenes, GameObjects, components, and C# scripts interact in Unity.

  2. Basic movement

    I worked on implementing the player movement mechanics so the player could navigate the halls of the old Metsola campus while evading Peely.

  3. Collectable potatoes

    I implemented the interaction and collection logic for the kumi-potatoes scattered around the campus, tracking the player's progress toward collecting all 8 potatoes needed to escape.
